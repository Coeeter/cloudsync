# Durable project context

Cloudsync is a personal single-owner archive. Production currently runs Dokploy/PostgreSQL with originals in private Singapore S3 and signed CloudFront delivery. Doppler project cloudsync (dev/prod) is the secret source. Nas approved local migration to Cloudflare Workers + D1, client previews, and AWS Lambda ZIPs on 2026-10-12; see [spec](cloudflare/spec.md) and [plan](cloudflare/plan.md). This supersedes docs/aws-serverless, which is retained as historical research. No deployment, production changes, shared-state adoption, paid fixtures, commit or push is authorized.
